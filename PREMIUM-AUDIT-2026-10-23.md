# Kubo Web — Premium Audit / 23 Oct 2026

## Verdict
The previous build was technically polished but visually over-designed: too many sections competing for attention, repeated rounded cards, repeated dark/light UI panels, too much explanatory copy, and insufficient whitespace. Premium references feel directed because they remove more than they add.

## First-pass changes applied
- Rebuilt the hero from centered SaaS landing-page composition into an asymmetric studio cover.
- Made real published work the visual proof instead of conceptual UI.
- Reduced the homepage narrative from 12+ visual chapters to a tighter 9-part sequence.
- Removed AgencyStatement, StudioShowcase, StackRail and Comparison from the homepage flow because they repeated the same claim and visual language.
- Kept factual pricing, real projects, tracking and technical SEO intact.

## Second-pass audit criteria
1. Hierarchy: one dominant idea per viewport.
2. Density: no section should read as a dashboard unless the content genuinely needs UI.
3. Shape language: reduce excessive pills and rounded cards; use borders, whitespace and editorial alignment.
4. Typography: large display type must be paired with restrained body copy and fewer labels.
5. Motion: motion should reveal hierarchy or depth, never exist only as decoration.
6. Proof: published work must remain more prominent than process explanations.
7. Mobile: no desktop composition should simply shrink; overlaps and typography require mobile-specific layouts.
8. Conversion: one primary CTA per decision point, with WhatsApp as the principal contact action.
9. Trust: no invented metrics, awards, testimonials, logos or results.
10. Performance/accessibility: preserve lazy loading, reduced-motion behavior, semantic links, keyboard interaction, SEO, sitemap and true 404.

## Remaining second-pass targets
- Simplify Services into a more editorial index with less hover-dependent decoration.
- Reduce visual complexity inside Process previews on small screens.
- Make Pricing feel like an investment conversation, not a SaaS pricing configurator.
- Tighten FAQ copy and spacing.
- Make final CTA/footer feel like one continuous closing composition.
- Audit all secondary pages against the same shape/typography system.
- Run build/lint and production checks before release.
